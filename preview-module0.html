PREPARE · CHAPTER 00.1

Tooling should follow the problem.

Install Podman, Buildah, Skopeo, OpenTofu, Git, and curl. Follow only the instructions for your environment.

Run in an Ubuntu terminal, including Ubuntu in WSL 2.

01Install runtime and CLI tools+
TERMINAL
sudo apt-get update
sudo apt-get install -y podman buildah skopeo git curl less ca-certificates gnupg
02Download the OpenTofu installer+
TERMINAL
curl --proto '=https' --tlsv1.2 -fsSL https://get.opentofu.org/install-opentofu.sh -o install-opentofu.sh
03Review, then install OpenTofu+
TERMINAL
less install-opentofu.sh
chmod +x install-opentofu.sh
./install-opentofu.sh --install-method deb
rm -f install-opentofu.sh
04Verify+
TERMINAL
podman --version
buildah --version
skopeo --version
tofu version
git --version
curl --version

ⓘ Review downloaded scripts before executing. Run these commands in Linux, not PowerShell.

Use DNF on Fedora or RHEL. RHEL hosts may require registered/enabled repositories and organization-approved packages.

01Install the container toolchain+
TERMINAL
sudo dnf install -y podman buildah skopeo git curl less ca-certificates
02Download official OpenTofu setup+
TERMINAL
curl --proto '=https' --tlsv1.2 -fsSL https://get.opentofu.org/install-opentofu.sh -o install-opentofu.sh
03Review, then install using RPM+
TERMINAL
less install-opentofu.sh
chmod +x install-opentofu.sh
./install-opentofu.sh --install-method rpm
rm -f install-opentofu.sh
04Verify+
TERMINAL
podman --version
buildah --version
skopeo --version
tofu version

ⓘ On RHEL, package availability or repository policy may require your administrator. Fedora usually provides the tools directly from its configured repositories.

Use an open-source Linux guest with Lima for the Linux-specific labs. Run Buildah, Podman, Skopeo, and OpenTofu in that guest.

01Install host utilities with Homebrew+
TERMINAL
brew update
brew install lima git curl
02Start a Linux lab VM+
TERMINAL
limactl start --name=course-linux template:default
limactl shell course-linux
03Inside the Linux guest: install tools+
TERMINAL
sudo apt-get update
sudo apt-get install -y podman buildah skopeo git curl less ca-certificates gnupg
04Inside the guest: install OpenTofu+
TERMINAL
curl --proto '=https' --tlsv1.2 -fsSL https://get.opentofu.org/install-opentofu.sh -o install-opentofu.sh
less install-opentofu.sh
chmod +x install-opentofu.sh
./install-opentofu.sh --install-method deb
rm -f install-opentofu.sh
05Verify inside the guest+
TERMINAL
podman --version
buildah --version
skopeo --version
tofu version

ⓘ Homebrew itself must already be installed. Keep the course commands together inside the Lima guest.
