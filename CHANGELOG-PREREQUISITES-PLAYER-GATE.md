# Narration playback gate — Course Prerequisites

- Main course play button and waveform cannot start narration before the learner chooses **Check course prerequisites** on the opening welcome card.
- The welcome-card click is stored locally and unlocks playback when returning from the Course Prerequisites page. It does **not** falsely report that the OS check was completed.
- Prerequisites assessment continues to require self-reported test values before the Continue to 00.0 link unlocks.
- Course navigation and reading remain accessible even when audio is locked; narration stays paused.
- The offline course preview uses the same behavior.
